# Konqi-Theme-Suite
A theming collection with KDE's mascot Konqi. Right now only splash screens are added, but more options will be available soon.

Install:
Select a splash screen and add to ./local/share/plasma/look-and-feel then go to System Settings > Colors and Themes > Splash Screen and it should show up.
